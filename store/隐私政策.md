# 并读隐私政策

更新日期：2026 年 11 月 22 日

并读是一款在 Chrome 中阅读和翻译网页、图片与文件的独立扩展。使用翻译时，你的浏览器直接连接 DeepSeek 官方接口。你使用自己的 DeepSeek API 密钥，服务费用记在你的 DeepSeek 账户。

## 什么时候会发送内容

- 点击网页翻译、使用选区或输入框翻译、按住 Alt 指向段落，或开启字幕翻译时，并读会发送对应的文字、目标语言及你填写的术语偏好。双语阅读会预先翻译阅读位置附近的段落；“整页双语”会处理全文。
- 为某个网站或本地网页开启自动翻译后，再次访问对应页面会自动触发上述请求。本地网页即使从电脑直接打开，翻译时也会联网。可在扩展弹窗关闭该网站或文件的自动翻译。
- 翻译图片时，并读会发送所选图片的像素。导入 PDF、EPUB、字幕或文本后，点击翻译会发送提取的待译文字。扫描 PDF 的文字识别会发送需要识别的整页图像；勾选“对每页使用文字识别”会逐页发送图像。原文件的读取与译本导出在浏览器中完成。
- 点击“测试连接”会发送一条预设的测试短句。发往 DeepSeek 的请求使用你的 API 密钥进行身份验证。DeepSeek 作为服务接收方也能看到建立连接所需的网络信息，例如 IP 地址。

## 保存在本机的数据

并读在当前 Chrome 配置的扩展存储中保存密钥、目标语言、术语表、自动翻译和浮球显示偏好。后两项按网站域名或本地文件路径记录。最近的部分文本和译文会暂存在扩展运行内存中，以减少重复请求。导出文件由你保存在自己的设备上。

## 数据用途和接收方

并读仅为你启用的翻译、文字识别和相关设置处理数据。翻译内容直接发往 api.deepseek.com。并读开发者不运营接收这些内容的中转服务器，不出售用户数据，也不将其用于广告、跟踪浏览活动或信用评估。DeepSeek 对其收到的请求按其开放平台适用条款处理。你可以在自己的 DeepSeek 开放平台账户管理密钥和用量。

## 删除与联系

你可以在“翻译设置”清空密钥或术语表并保存，在对应网站关闭自动翻译，或在 Chrome 扩展详情中撤回本地文件访问权限。移除扩展会清除该配置中的扩展本地存储；已导出的文件可以在设备上自行删除。如需停用密钥，可在 DeepSeek 开放平台撤销。如需联系并读开发者，请使用 Chrome 网上应用店并读详情页的开发者联系方式。
