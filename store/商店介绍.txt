名称
并读 · 双语网页与文档翻译

简短介绍
在原网页逐段对照阅读，翻译扫描 PDF，导出双语 EPUB。使用自己的 DeepSeek API 密钥。

详细介绍
读外语长文时，点一下网页右侧的「译」，就能在原段旁看到译文。并读先翻译你正在看的部分，再随滚动处理后面的段落。标题、链接、列表和表格跟随网页本身的排版。你可以随时切换双语、仅看译文或恢复原文，也可以只为指定网站开启自动翻译。

阅读文档
• PDF 可导出原页与译页交替的双语版本，也可以只导出译页。扫描 PDF 可按页识别文字；放不进原位置的译文会排在续页。
• 可重排 EPUB 支持导出双语电子书，在原本的章节中读原文和译文，保留目录、插图和链接。固定版式 EPUB 可选择双语文本导出。
• 本地 HTML 可直接翻译。首次使用时，请在 Chrome 的扩展详情页开启「允许访问文件网址」。

翻译一小段
选中文字后从右键菜单翻译；在输入框中按 Alt+I 可翻译正在编辑的文字。还可以翻译图片、导出保留时间轴的字幕，或在提供标准字幕轨的视频里显示双语字幕。

开始使用
打开并读的「翻译设置」，保存自己的 DeepSeek API 密钥，选择目标语言。扩展可免费安装，翻译和扫描页文字识别由 DeepSeek 按你的账户用量计费。翻译时，所选文字、图片或待识别的扫描页会直接发送给 DeepSeek。并读由独立开发者提供。
