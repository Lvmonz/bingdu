# 并读审核填写说明

## 单一用途

在用户正在阅读或编辑的位置提供翻译。网页、输入框、图片、字幕、PDF 和 EPUB 是这一用途支持的内容格式。

## 权限用途

- storage：在本机保存用户填写的 DeepSeek API 密钥、目标语言、术语和各网站或本地文件的阅读偏好。
- contextMenus：让用户在网页上通过右键对选区、图片或输入框发起翻译。
- activeTab：用户点击扩展图标时，识别当前标签页、显示页面可用状态，向该页发送翻译操作。
- sidePanel：在 Chrome 侧栏展示设置、文件选择和译文导出。
- 网页内容脚本（HTTP、HTTPS 及其中的框架）：在网页中显示翻译控件，按用户操作或其开启的网站规则逐段插入译文。file 匹配支持用户另行授权的本地 HTML。访问所有网页是为了在用户选定的网页上原位翻译，自动翻译按保存的规则触发。
- api.deepseek.com：使用用户自己的密钥从其浏览器直接调用翻译或扫描页文字识别接口。

## 数据使用

在后台披露网站内容和身份验证信息。用户主动选择翻译邮件、聊天或其他私人通信时，相关正文也属于可能处理的个人通讯。网站或本地文件的自动翻译及浮球偏好会在本地记录域名或文件路径，按后台对网页历史的定义披露该用途。没有浏览记录上传服务。并读不采集点击流、键盘记录或广告数据。填写与公开隐私政策一致。

翻译与识别通过 HTTPS 返回数据。扩展脚本、PDF 解析器、EPUB 处理库和 PDF 工作线程随包提供。本版本不从服务器加载或执行程序代码。

## 功能验证说明

安装后打开「翻译设置」，填写有可用额度的 DeepSeek API 密钥，点击「保存设置」「测试连接」。在含有英文段落的普通网页点击右侧「译」，检查双语阅读、仅看译文、恢复原文；无需登录并读。侧栏选择可重排 EPUB 或 PDF 后点击「翻译」并导出。扫描 PDF 的文字识别需要 DeepSeek 账户有对应额度。安装包不包含通用测试密钥。

## 后续更新

修改 manifest.json 的 version 后运行 python3 store/package.py，即在桌面生成带版本号的完整 ZIP。在原有商店项目的“软件包”上传新版本，按变更更新商店素材、隐私声明，提交审核。维持同一条目可让已从商店安装的用户跟随 Chrome 自动更新。
