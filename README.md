# 并读

并读是一款使用自己的 DeepSeek 密钥翻译网页、视频字幕和文档的 Chrome 扩展。可以在原文下方对照阅读，也可以只看目标语言。网页翻译和 YouTube 字幕翻译可分别开启。翻译模型 ID 为 `deepseek-flash`。

[新电脑安装与开发](#在新电脑上开发) · [一键发布商店更新](store/README.md) · [资产清单](docs/inventory.md) · [隐私政策](store/隐私政策.md)

## 安装和使用

1. 打开 Chrome 的 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」。
2. 选择本 README 和 manifest.json 所在的目录。在工具栏固定扩展后，点击图标可打开网页翻译弹窗。
3. 初次使用时，点击「翻译设置」，填写 DeepSeek API Key 并保存。可用「测试连接」验证服务。目标语言默认是简体中文，输入框翻译的目标默认是英语。
4. 刷新安装或更新前已打开的网页。单击网页右侧的「译」，或在工具栏弹窗点击「翻译网页」，即可从当前位置开始双语阅读。再次单击「译」恢复原文。
5. 指针停在浮球约半秒可展开菜单。触屏和键盘可用「更多操作」展开。可以切换「仅看译文」或「切换双语」，也可以选择在当前网站隐藏浮球，随后在工具栏弹窗重新启用。弹窗也可直接改目标语言或勾选「自动翻译此网站」。在阅读中改目标语言后，扩展会按新语言重译。
6. 阅读长文时，扩展优先请求眼前段落，提前准备下方约两屏的译文。段落接近屏幕时才把译文放入正文。点击弹窗的「文件翻译」可进入 PDF、EPUB 等文件工具。侧栏保留「整页双语」供需要立即处理全文时使用。

直接打开电脑上的 HTML 或 XHTML 时，在 `chrome://extensions` 找到「并读」，进入「详情」，确认已开启「允许访问文件网址」。如果刚更新过桌面版，先在扩展卡片点一次重新加载，再刷新本地网页。浮球、双语和仅译文的操作与在线网页相同。「自动翻译此文件」只对当前文件生效。

| 场景 | 操作和结果 |
| --- | --- |
| 阅读网页 | 双语译文随原段落、列表或单元格排版，长段落换行，短标签按空间决定是否同行。仅译文模式直接替换原位置的文字，保留链接和强调。开启「自动翻译此网站」后，下次打开同一域名会自动进入双语模式。 |
| 临时查一句 | 选中文字后从右键菜单翻译，或按住 Alt 将鼠标移入段落。译文显示在页面角落。 |
| 编写外语 | 聚焦文本输入框并按 Alt+I，将原文替换为译文。翻译期间若输入已变化，保留新内容。 |
| 看视频 | 在 YouTube 打开并读浮球或扩展菜单，选目标语言，再点「双语字幕」或「仅译文字幕」。双语在同一个框内上排显示原声字幕，下排显示译文。仅译文只显示目标语言。「关闭字幕翻译」恢复播放器原先的字幕选择。其他网站仍可用侧栏的「切换视频双语字幕」。 |
| 翻译文件 | 上传 TXT、SRT、VTT、ASS、PDF、EPUB 或 PNG、JPEG、WebP。字幕导出保留时间轴。PDF 和 EPUB 可导出原格式或双语 TXT，图片导出识别到的文字译文。 |
| 翻译网页图片 | 右键图片触发。若网页禁止跨域读取图片像素，可下载后上传到侧栏。 |
| 统一术语 | 在设置里填写术语偏好，模型翻译时读取这些偏好。 |

## PDF 和 EPUB 导出

上传文件后选择导出格式，点击「翻译」。处理完成后，点击「导出 PDF」或「导出 EPUB」。

- **双语 PDF**按源页顺序放入原页和译页。译页保留原页尺寸、图像和版面，能够放下的译文覆盖在对应文字区域。原位置容纳不下、背景复杂或没有可靠坐标的译文会排到对应续页。也可选择「译文 PDF」省略原页。译文以图层显示，原 PDF 的文本层仍是原文。
- **扫描 PDF**按页自动判断。页面没有可提取文字时，扩展会发送该页图像到 DeepSeek 文字识别接口，再将识别出的文字交给 Flash 翻译。对带错误文字层或有文字和扫描图混排的文件，可以勾选「对每页使用文字识别」。表格、公式和复杂扫描版面可能需要查看续页。文字识别单独按页计费。[DeepSeek 文字识别说明](https://api-docs.deepseek.com/guides/ocr/)
- **双语 EPUB**在可重排的正文中插入段落译文，同一本书里保留原文、章节顺序、目录、插图和链接。导出的 `.epub` 可导入阅读器。固定版式 EPUB 可切换到双语 TXT。受加密保护的正文无法读取。

Alt+A 可切换网页双语。Chrome 若把快捷键分配给了其他扩展，可在 `chrome://extensions/shortcuts` 调整。

API Key 保存在本机 Chrome 此扩展的本地存储中。翻译时，相应文本、图片和术语偏好会发送到 DeepSeek 官方 API。仓库文件不含用户提供的 Key。PDF.js 6.5.438、pdf-lib 1.17.1 和 fflate 0.8.3 随扩展本地加载，许可文件位于 `vendor`。

## 在新电脑上开发

安装 Git 和桌面版 Chrome，然后获取源码。

```sh
git clone https://github.com/Lvmonz/bingdu.git
cd bingdu
```

在 Chrome 的扩展管理页加载这个目录即可开发。修改脚本后，在扩展卡片点「重新加载」，再刷新测试网页。换电脑继续时，先推送本机提交，在另一台电脑运行 `git pull --ff-only` 拉取已合并的改动。[组件与数据流](docs/architecture.md)

浏览器自动测试使用 Node.js 22 或 24，打包与发版使用 Python 3.10 或更新版本。以下命令在项目根目录运行。Windows 的 Python 命令可用 `py -3` 替换 `python3`。

```sh
npm ci
npx playwright install chromium
npm test
python3 -X utf8 tests/check_repository.py
python3 -X utf8 -m unittest discover -s tests -p "test_release*.py"
python3 -X utf8 store/package.py --output dist
```

最后一个命令会直接生成可提交审核的 ZIP。也可以在 GitHub 的「Actions → 并读检查与打包 → Run workflow」选择分支并运行，完成后在该次运行的 Artifacts 区域下载 `bingdu-chrome-store-zip`。解压下载物即可取得商店所用的 ZIP。[构建任务](https://github.com/Lvmonz/bingdu/actions/workflows/ci.yml)

## 一键发布商店更新

macOS 双击 `store/一键发版.command`，Windows 双击 `store/release.cmd`，Linux 运行 `./store/release.sh`。新电脑首次需要配置 Google 授权。之后发版工具会查询并读原条目、选择版本、打包、上传并提交审核。Google 审核通过后按原条目的发布范围分发。源码提交与商店提审各自触发。[首次授权、状态查询及重试](store/README.md)

商店配图、文案及审核填写说明保存在 [商店材料](store/) 中。网页匹配和字幕交互的改动可以在本地扩展中验证，随后按需要发版。
