# 并读维护资产

| 资产 | 来源和用途 | 仓库位置 |
| --- | --- | --- |
| 扩展入口、图标和网页界面 | 桌面加载版的自有工程。Chrome 依据清单直接加载 JavaScript、CSS 和 HTML | 根目录、`icons/` |
| 网页翻译、YouTube 字幕和文件导出 | 网页分页取词、翻译请求、播放器字幕轨、PDF 和 EPUB 处理是独立模块 | [组件与数据流](architecture.md) |
| 文档处理库 | PDF.js 6.5.438、pdf-lib 1.17.1、fflate 0.8.3 的本地发行文件及各自许可，随扩展打包 | `vendor/` |
| 商店条目材料 | 上架文案、审核说明、公开隐私政策正文、三张示例截图和一张宣传图。128 像素商店图标与扩展共用 | `store/`、`store/assets/`、`icons/icon-128.png` |
| 打包与提审工具 | 本地脚本按清单生成 ZIP，使用官方 API 更新同一商店条目 | `store/package.py`、`store/release.py`、系统启动脚本 |
| 自动检查 | 使用临时目录和模拟响应复现页面翻译和商店操作，开发依赖由锁文件记录 | `tests/`、`package-lock.json`、`.github/workflows/ci.yml` |
| 新电脑自行配置 | 阅读者在并读中填写自己的翻译密钥。维护者使用有原条目权限的 Google 账号，并在本机导入桌面 OAuth 客户端、授权发布 | 浏览器本地存储、系统凭据库及发版状态目录 |

主分支维护扩展源代码和工具。初始纳管时的清单版本为 0.4.4。安装包版本由 `manifest.json` 决定，实际商店版本及审核状态以开发者后台为准。GitHub 的提交和 Chrome 商店的发布各有自己的版本记录。

本机功能对照记录、浏览器采样、旧商店 ZIP、开发者后台截图和授权文件保留在维护者电脑。公开工程从自身的扩展源码运行，复现自动测试使用仓库内的测试页面。工程的服务端依赖是 DeepSeek API 和维护者使用的 Chrome Web Store API，扩展没有自建服务或数据库。
